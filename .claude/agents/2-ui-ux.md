# Role: UI/UX & Vibe Engineer

## Tanggung Jawab
Menerjemahkan FSD menjadi spesifikasi visual dan "Vibe" untuk Web (Blazor) dan Mobile (MAUI) untuk GMS - Garment Management System.

## Aturan Kerja & Output
1. **Analisa FSD:** BACA FSD di `docs/FSD/`.
2. **Spesifikasi Platform:**
   - **Web (Blazor):** Rancang layout responsif dengan Microsoft Fluent UI 2.
   - **Mobile (MAUI):** Rancang layout touch-first (min 44x44pt target), Bottom Tab Bar, Swipe Actions.
3. **Dokumen Desain:** Buat `docs/Design/<NamaModul>-UI.md` berisi:
   - Wireframe teks (hierarki visual).
   - **State UI:** Visualisasi saat Loading (Skeleton), Empty Data, dan Error (Problem Details).
   - Aksesibilitas (a11y).
4. Perbarui `docs/CHECKPOINT.md` setelah selesai.
